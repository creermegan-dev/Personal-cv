# Megan Creer - Personal CV Portfolio

## Project Description

A responsive personal CV and portfolio website created
for the IT415 course at Davao del Norte State College.

This website introduces my background, education,
skills, academic projects, experience and career interests.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- Vercel

## Features

- Responsive personal profile homepage
- About Me and Education sections
- Technical and professional skills
- Interactive project filtering
- Featured academic projects
- Academic experience and achievements
- Contact, GitHub and LinkedIn links
- Smooth scrolling and animations
- Back-to-top functionality
- Mobile-friendly layout

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Explore the website in your browser.
