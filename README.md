# Megan Creer — Personal CV Portfolio

A responsive personal CV and portfolio website for Megan Creer, a fourth-year
Bachelor of Science in Information Technology student at Davao del Norte State
College and an aspiring software developer.

## Website Content

- Personal profile and career objective
- Contact details and professional profiles
- Educational background
- Technical and professional skills
- Academic and development projects
- Academic experience
- Learning and achievements

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- Vercel for deployment

## Features

- Responsive desktop, tablet, and mobile layouts
- Smooth navigation and scrolling
- Project category filtering
- Hover and scroll-based animations
- Reduced-motion accessibility support
- Back-to-top control
- Accessible external links and contact actions
